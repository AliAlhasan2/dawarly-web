دورلي - ابدأ من هنا
==================

1) فك الضغط.
2) افتح المجلد في VS Code.
3) افتح Terminal واكتب: npm install
4) شغّل: npm run dev
5) افتح: http://localhost:3000

سترى شكلاً جاهزاً ببيانات توضيحية، حتى قبل ربط قاعدة البيانات.

لتفعيل الإعلانات الحقيقية وتسجيل الدخول:
- أنشئ مشروع Supabase.
- شغّل ملف supabase/schema.sql من SQL Editor.
- انسخ .env.example إلى .env.local وضع مفاتيح Supabase العامة.
- أعد تشغيل npm run dev.
- اقرأ README.md لمعلومات المشرف والنشر على Vercel.

المشروع لا يحتوي بيانات دخول أو مفاتيح خاصة، ولا يدّعي أنه منشور على الإنترنت مسبقاً.
